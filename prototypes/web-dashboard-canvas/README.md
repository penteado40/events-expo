# PROTÓTIPO: telas web do dashboard (descartável)

Gerador das 50 telas desktop da página **Web** do canvas
[events-expo · Design D](https://claude.ai/artifact/XBggR1iFpMS3Ht8x7Hw8k6) (PROJ-246).

Não é código do app. Fica aqui como fonte primária do protótipo; o canvas é a referência de design.

- `lib.py`: tokens de cor claro e escuro, casca (menu e cabeçalho), componentes.
- `event.py`: dados do Event de exemplo e as visões de programação (lista, compacta, dias).
- `s_group.py`, `s_event.py`, `s_rest.py`: as telas.
- `python3 build.py <pasta>/project` escreve os `.dc.html` e um `manifest.json` ao lado.
